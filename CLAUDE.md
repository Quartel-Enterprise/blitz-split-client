# Bora Rachar

An app to split bills among friends, offline first and with an optional account. It is **Bora Rachar** in
Portuguese and **Blitz Split** in every other language (English is the fallback); Blitz Split is also the code
name: the package `com.quare.blitzsplit`, the Gradle project, the `blitzsplit.*` convention plugins. The apps keep the legacy Blitz Split `applicationId` and bundle id, since they
replace it in the stores.

## Layout

One monorepo, Kotlin shared up to the ViewModel, three native UIs:

| Path | What it is |
| --- | --- |
| `core/*` | KMP domain and data: model, utils, presentation bridge, navigation, profile, account, sync, Room and Supabase providers, and the `:testing` fakes |
| `feature/*` | KMP presentation of each screen: ViewModel, `UiState`, `UiEvent`, `UiAction` |
| `shared/` | The composition root (Koin), the Apple framework `Shared` and the JS library `blitzsplit-shared` |
| `android/*`, `androidApp/` | Jetpack Compose UI (Material 3 Expressive, Navigation 3) and the Android app |
| `iosApp/` | SwiftUI app for iOS, iPadOS and macOS 26 (Liquid Glass), generated by XcodeGen from `project.yml` |
| `webApp/` | Vite + React 19 + Tailwind 4 + shadcn/ui, with Room's SQLite in a Web Worker (OPFS) |
| `build-logic/` | `blitzsplit.kotlin.multiplatform` and `blitzsplit.android.compose` |

The backend (Supabase: migrations, edge functions, auth settings) lives in the `blitz-split-api` repository.

## Build and test

```bash
./gradlew build                       # every module
./gradlew jvmTest                     # the unit tests (commonTest on the jvm target)
./gradlew :koverVerifyCi              # 80% line coverage of core and feature
./gradlew assertModuleGraph           # the module dependency rules
./scripts/ktlint.sh [--format]        # Kotlin style, Quare ruleset
./scripts/cpd.sh                      # no new copied code in Kotlin, Swift and TypeScript (jscpd)
./gradlew :androidApp:assembleDebug   # Android
./iosApp/generate-project.sh          # then build the BoraRachar-iOS or BoraRachar-macOS scheme in Xcode
npm --prefix webApp run dev           # web dev server (builds the shared JS library first); `build` for dist/
```

First-time setup (JDK, Android SDK, Xcode, XcodeGen, Node, Supabase settings): [docs/getting-started.md](docs/getting-started.md).

## Where decisions live

- The docs under `docs/`, indexed in [docs/ai_agents.md](docs/ai_agents.md): the architecture decisions (shared up
  to the ViewModel, no SKIE, one back stack, offline first, auth and the recovery code) and how to apply them.
- Product decisions, to follow on every platform:
  - The recovery code's "Conectar Google ou Apple em vez disso" expands in place into one button per provider
    (`RecoveryCodeUiState.isConnectExpanded`).
  - Apple's sign in button comes before Google's on iOS, macOS and in the browser of an Apple device (Mac, iPhone,
    iPad); Google comes first on Android and in any other browser.
  - Every UI is in English and Portuguese, English for any other language. The brand badge shows the currency
    symbol of the device's region, `$` when there is none.
  - The home shows the four tabs of the design (Grupos, Saldos, Contatos, Atividade); the three not built yet
    answer "Em breve" (`GroupsUiAction.ShowComingSoon`).
  - "Editar perfil": the avatar's pencil opens the photo menu (take a photo where there is a camera, choose from the
    gallery, use the Google or Apple account's photo while it isn't the one shown, remove the photo), and the avatar
    color picker only shows while there is no photo (`EditProfileUiState.showsAvatarColors`).
  - Member names have 2 to 40 letters, like a profile's, since joining without a profile makes one from it.
  - "Novo grupo": tapping the group's avatar cycles its color through the palette (no shapes yet), and Moeda starts
    in the currency of the device's region (`GroupCurrency.ofRegion`), USD when the list has none. A name already in
    the group offers two nicknames, "Ana P." (the initial of whoever adds the name, so the creator's in "Novo
    grupo") and "Ana 2".
  - "Convidar" opens in the new group's place right after it is created (`Route.Invite`). The server makes each
    group's invite code, and only the group's creator may change it ("Trocar link", not built yet), which
    invalidates the old link.
  - A group tapped on the home opens "Despesas do grupo" (`Route.GroupDetail`): the bills by day, the most recent on
    top, with "Rachar conta" (Android's extended FAB, iOS's glass toolbar item, a primary button on macOS and the
    web). Its tabs Despesas / Saldos / Membros take each other's place (`openGroupTab`), also through Convidar, so
    the group never stacks over itself. Convidar's "Ir para o grupo" opens it too.
  - A bill tapped there opens "Conta" (`Route.BillDetail`): the bill, "Sua parte" and the split over every member,
    with Editar and Apagar in the top bar (no Compartilhar, comments, attachments nor history yet). A phone opens it
    full screen; Android tablets open it as a dialog, iPad and Mac as a sheet, and the web as a side sheet (a drawer
    on a phone), all over the group.
  - Any member may edit or delete a bill. "Editar conta" is "Rachar conta" filled in (`Route.SplitBill` with the
    bill's id), keeping who created it and when, with "Qualquer pessoa do grupo pode editar ou apagar." and "Apagar
    conta"; saving goes back to Conta. Members who left the group are dropped from the edited split, but a payer who
    left stays its payer ("Ex-membro") until someone else is picked, and someone who joined while it was being
    edited starts out of an Igual split. Last-Write-Wins:
    when someone else's save syncs while editing, a banner says who changed it and when
    (`SplitBillUiState.conflict`, the server's `expenses.updated_by`), what was typed stays, and saving wins.
  - Apagar asks first: "“X” sai do grupo e a parte de cada um nesta conta deixa de contar.", plus "Você deixa de
    dever/receber R$ Y" while the bill moves the device user's balance (`BillDeletion`). It deletes offline as a
    tombstone and goes back to the group, past Conta. A bill someone else deleted while open closes, and Despesas
    do grupo says "Esta conta foi apagada" once it is on top (`GroupDetailUiState.showsBillDeletedNotice`); never
    for a bill this device deleted (`NoticeBillGone`).
  - "Membros" (`Route.Members`) is the group's tab, and opens from Convidar's "Ver quem já entrou". Any member may
    rename and add members, but only a member who hasn't joined can be removed ("Remover do grupo" is disabled for
    someone who joined), after confirming "Remover Carla do grupo?" (`MembersUiState.memberToRemove`). "Convite
    pessoal" answers "Em breve". Each member shows their balance ("+R$ 223,50 a receber"), and someone with an open
    balance can't be removed either ("Carla tem saldo em aberto", `MembersMember.hasOpenBalance`).
  - "Saldos" (`Route.Balances`) is the group's tab: each pair once, already netted (no simplifying debts across the
    group), "Com você" then "Entre os outros", from the bills' payers and shares (`GroupBalances`, several payers
    included) minus the payments recorded. Rows end in "Acertar" (you owe), "Recebi" (owed to you) or "Já pagou"
    (between others), which all open "Registrar pagamento". Once there were bills and nobody owes anything, "Todo
    mundo acertou" offers "Apagar grupo" ("Em breve" for now).
  - "Seu saldo neste grupo" sits above the tabs of Despesas, Saldos and Membros while the group has a bill: "R$ 0,00 ·
    você está quitado" when settled, and its "Acertar" opens Registrar pagamento with whoever you owe the most, hidden
    when you owe nobody.
  - "Registrar pagamento" (`Route.RegisterPayment`) records a payment made outside the app, which any member may
    record between any two members, with no confirmation by whoever received it: up to the pair's debt, never over
    ("Ana te deve R$ 162,30. Use até esse valor."), partial payments allowed, Pix / Dinheiro / Transferência / Outro
    and "Quando" (date and time, never after now). "Acertar" opens it too: paying through the receiver's Pix key
    (4.5) comes later, since other members' keys never reach the device. It is a bottom sheet on an Android phone
    and a dialog on its tablets, a sheet on iOS and macOS, a dialog on the web (a drawer on a phone). It works
    offline. A debt with someone no longer in the group stays until it is paid: the form shows them as "Ex-membro"
    and closes only once the debt or the group is gone. A payment is never edited: "Pagamento de Ana registrado."
    offers "Desfazer", and the payment shows in Despesas as an "acerto", where tapping it asks "Apagar este acerto?" (a
    tombstone, offline too). No
    notifications nor Atividade yet, and no warning when a bill is edited after a payment (7.4b).
  - The group's ⋮ menu (⋯ on iOS, macOS and the web) holds Editar grupo, Sair do grupo and Apagar grupo; the last two
    answer "Em breve". "Editar grupo" (`Route.EditGroup`) has Novo grupo's fields: tapping
    the avatar or "Trocar cor" cycles its color (groups have no photo yet), the name has 1 to 40 letters and the type
    stays editable; there is no "Divisão padrão" yet. Moeda locks once the group has a bill on the device ("Não muda
    depois da primeira despesa"), with no server check. Any member may edit, offline too: the change holds on the
    device and syncs later, and only the fields this person changed are saved, so another member's newer edit to the
    rest stays. Salvar stays disabled until something changed. It is a sheet on iOS and macOS, a dialog on the web and
    on Android tablets.
  - "Rachar conta" (`Route.SplitBill`): one person paid the whole bill (several payers aren't built yet), "Quando"
    picks date and time, never after now, and there is no category yet. A bill is 0.01 to 100 million in the group's currency with a
    description; Salvar stays disabled until both are valid and the split adds up, and saving goes back to the
    group. "Dividir" splits by Igual, Valores, % (whole numbers adding up to 100) or Partes, and only changes the
    bill on "Pronto". The cents a split can't share evenly go to whoever paid, while they are in the split.
    Changing the total redoes a "Valores" split proportionally. Payers and shares live inside the bill (one
    Last-Write-Wins row).
  - A group's invite link is `https://blitzsplit.com/g/<code>` (borarachar.com will redirect to blitzsplit.com).
    Joining through it lands on Membros with "Você entrou como <nome>" and, while the account has no Google or Apple,
    "Proteja seu acesso", which opens the Perfil. Joining with no profile on the device makes one from the name and
    color joined as. A member someone else already joined as says "Se era você, fale com <criador>": "Liberar nome"
    isn't built yet.
  - The home's "Entrar com link ou QR" opens the reader (`Route.JoinWithLink`) on every platform: the camera reads
    an invite's QR and keeps reading after a wrong one ("Esse QR não é um convite do Bora Rachar" for a few
    seconds), and "Tem o link?" under it takes a pasted or typed link. Only links on blitzsplit.com and
    borarachar.com count as invites there, since a QR can hold any site's address. Android and iOS open it full
    screen, macOS as a sheet and the web as a dialog (a drawer on a phone), whose camera reads through the browser's
    BarcodeDetector. An invite no longer valid offers "Escanear outro QR", which goes back to the reader; that reader
    ignores the QR of the invite that just failed, which may still be in front of the camera, so only another QR or
    a pasted link opens.
  - Android's "Tirar foto" asks for the camera first. Once it is refused for good, a snackbar "Permita a câmera nas
    configurações" offers "Configurações", which opens the app's settings page.
  - Minimum iOS 26 and macOS 26, so Liquid Glass is native with no fallbacks.
  - The Android UI uses the AndroidX Compose artifacts (BOM), not the JetBrains Compose coordinates; only the shared
    ViewModels take JetBrains' multiplatform lifecycle.
  - The Android launcher icon comes from the legacy app until Bora Rachar has its own.
- Product choices nobody wrote down yet are Pierre's call: ask before settling one.
