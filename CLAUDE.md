# Bora Rachar

An app to split bills among friends, offline first and with an optional account. It is **Bora Rachar** in
Portuguese and **Blitz Split** in every other language (English is the fallback); Blitz Split is also the code
name: the package `com.quare.blitzsplit`, the Gradle project, the `blitzsplit.*` convention plugins. The apps keep the legacy Blitz Split `applicationId` and bundle id, since they
replace it in the stores.

## Layout

One monorepo, Kotlin shared up to the ViewModel, three native UIs:

| Path | What it is |
| --- | --- |
| `core/*` | KMP domain and data: model, utils, presentation bridge, navigation, profile, account, sync, Room and Supabase providers, and the `:testing` fakes |
| `feature/*` | KMP presentation of each screen: ViewModel, `UiState`, `UiEvent`, `UiAction` |
| `shared/` | The composition root (Koin), the Apple framework `Shared` and the JS library `blitzsplit-shared` |
| `android/*`, `androidApp/` | Jetpack Compose UI (Material 3 Expressive, Navigation 3) and the Android app |
| `iosApp/` | SwiftUI app for iOS, iPadOS and macOS 26 (Liquid Glass), generated by XcodeGen from `project.yml` |
| `webApp/` | Vite + React 19 + Tailwind 4 + shadcn/ui, with Room's SQLite in a Web Worker (OPFS) |
| `build-logic/` | `blitzsplit.kotlin.multiplatform` and `blitzsplit.android.compose` |

The backend (Supabase: migrations, edge functions, auth settings) lives in the `blitz-split-api` repository.

## Build and test

```bash
./gradlew build                       # every module
./gradlew jvmTest                     # the unit tests (commonTest on the jvm target)
./gradlew :koverVerifyCi              # 80% line coverage of core and feature
./gradlew assertModuleGraph           # the module dependency rules
./scripts/ktlint.sh [--format]        # Kotlin style, Quare ruleset
./scripts/cpd.sh                      # no new copied code in Kotlin, Swift and TypeScript (jscpd)
./scripts/heavy-check.sh <command>    # run a heavy build (Gradle, xcodebuild, the web build) once no other worktree runs one
./gradlew :androidApp:assembleDebug   # Android
./iosApp/generate-project.sh          # then build the BoraRachar-iOS or BoraRachar-macOS scheme in Xcode
npm --prefix webApp run dev           # web dev server (builds the shared JS library first); `build` for dist/
```

First-time setup (JDK, Android SDK, Xcode, XcodeGen, Node, Supabase settings): [docs/getting-started.md](docs/getting-started.md).
