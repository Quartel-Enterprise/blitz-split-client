# Blitz Split

Split bills with friends, even offline. [Blitz Split](https://blitzsplit.com) (**Bora Rachar** in Portuguese) keeps
every group, bill and payment on your device first and syncs when the internet is back. An account is optional.

## ✨ Features

- **Offline first.** Create groups, split bills and record payments with no connection; everything waits in a queue
  and goes up on its own.
- **An account only if you want one.** Start anonymous, then connect Google or Apple, or keep a recovery code.
- **Every way to split.** Equally, by exact amounts, percentages, shares, or item by item, with the service charge
  and the couvert. Several people can pay one bill.
- **Read the receipt.** Take a photo of the receipt and the total, the place, the date and the items come filled in.
- **Know who owes whom.** Each pair netted once, across groups too, with partial payments, Pix and Bitcoin keys, and
  "Simplificar dívidas" when you want fewer transfers.
- **Charge and get paid.** Send a message to whoever owes you, or pay with a Pix code and mark it paid.
- **Categories that learn.** A map of words to categories that is yours, synced across your devices.
- **Invite with a link or a QR code.** Whoever joins finds their part of the old bills already there.
- **Activity and notifications** for what involves you, and statistics for each group.
- **Every screen size.** Phones, tablets, foldables (book and tabletop postures), the iPhone Duo, the web and the Mac,
  each drawn by its own native UI.
- **English, Portuguese, Spanish** (Latin American and Spain), **French, German, Italian, Polish, Dutch, Japanese, Turkish and Indonesian**, English for any
  other language.

## 🧱 One codebase, three native UIs

Kotlin Multiplatform is shared **up to the ViewModel**: every `ViewModel`, `UiState`, `UiEvent` and `UiAction` lives
in `:feature:*`, and three native UIs draw them, so the three platforms walk the same flow.

| Path | What it is |
| --- | --- |
| `core/*` | KMP domain and data: model, utils, navigation, profile, account, sync, Room and Supabase providers |
| `feature/*` | KMP presentation of each screen: ViewModel, `UiState`, `UiEvent`, `UiAction` |
| `shared/` | The composition root (Koin), the Apple framework `Shared` and the JS library `blitzsplit-shared` |
| `android/*`, `androidApp/` | Jetpack Compose UI (Material 3 Expressive, Navigation 3) and the Android app |
| `iosApp/` | SwiftUI app for iOS, iPadOS and macOS, generated by XcodeGen from `project.yml` |
| `webApp/` | Vite + React 19 + Tailwind 4 + shadcn/ui, with Room's SQLite in a Web Worker (OPFS) |
| `build-logic/` | The `blitzsplit.kotlin.multiplatform` and `blitzsplit.android.compose` convention plugins |

The backend (Supabase migrations, edge functions, auth settings) lives in the `blitz-split-api` repository.

See [Stack](docs/architecture/stack.md) and [Module structure](docs/architecture/module-structure.md) for the whole
picture.

## 🚀 Getting started

JDK 21, Android Studio, Xcode 27.1 with XcodeGen, and Node.js. The whole setup, and how to run each platform, is in
[Getting started](docs/getting-started.md). The everyday commands:

```bash
./gradlew build                       # every module
./gradlew jvmTest                     # the unit tests
./gradlew :androidApp:assembleDebug   # Android
./iosApp/generate-project.sh          # then build BoraRachar-iOS or BoraRachar-macOS in Xcode
npm --prefix webApp run dev           # web dev server
```

## 🤝 Contributing

Branches and pull request titles follow Conventional Commits types (`fix`, `feature`, `enhancement`, `refactor`,
`chore`). Before opening one, run `./scripts/ktlint.sh`, `./gradlew jvmTest :koverVerifyCi assertModuleGraph` and `./scripts/cpd.sh`. Code,
comments, docs and commit messages are in English; only the text a user sees is translated.
