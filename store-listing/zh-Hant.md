## Description

Blitz Split是和朋友、室友、家人或旅伴分帳的輕鬆方式。記下每個人付了多少，App就會算出誰欠誰多少，每個群組分開算，也會把所有群組加總起來算。

帳單，隨你怎麼分
• 平均分攤，或按金額、百分比、份數，甚至按每個人的收入分攤
• 按品項分攤：每道菜算給點的人，服務費和每人固定收費也一併算進去
• 不只一個人付錢？同一筆帳單可以加入多位付款人

掃描收據
• 拍下收據，品項、價格和總計自動填好
• 幫帳單附上照片、留下留言，大家不用再問這筆錢花到哪裡去

誰欠誰，一清二楚
• 每個群組有一個餘額，和每位一起分帳的人也各有一個餘額
• 簡化債務，用最少的付款次數結清
• 記錄現金、銀行轉帳或任何方式的付款。Blitz Split不經手任何金錢：你們照常互相付款，再標記為已付就好

為旅行、合租和聚會而生
• 為旅行、合租的家、聚會或任何事建立群組，每個群組都有自己的照片
• 每筆帳單使用各自的幣別，每種幣別的餘額分開計算
• 類別、搜尋和統計讓你看清錢都花在哪裡
• 把群組的帳單匯出成CSV或Excel

幾秒就能開始
• 不需要帳號就能開始：打開App，建立群組
• 透過連結或QR Code邀請別人，沒裝App的人也能用名字加入
• 使用Google或Apple登入，在手機、平板、電腦和網頁上同步所有內容

離線也能用
• 沒有網路也能新增帳單和付款：恢復連線後自動同步
• 「動態」會顯示每個群組裡的變化

免費，沒有廣告。支援淺色和深色模式。
